
# PLAYMOBIL SAC Training Center

An interactive multilingual training platform designed to help PLAYMOBIL customer service agents develop their knowledge, practice operational procedures and assess their skills.

## Features

- **Interactive Training Presentation** — customer service procedures, SAP workflows, practical examples and screenshots.
- **Game Center** — educational mini-games designed to reinforce knowledge through realistic scenarios and interactive challenges.
- **Final Assessment** — a 20-question quiz with scoring, feedback and answer explanations.
- **Multilingual Support** — available in English, Spanish and Serbian.
- **Responsive Design** — accessible on desktop, tablet and mobile devices.

## Technologies

- HTML5
- Tailwind CSS
- Alpine.js
- Vanilla JavaScript

## Getting Started

Open `index.html` in your browser and select your preferred language to begin training.
